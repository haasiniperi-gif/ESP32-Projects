# ESP32 Projects

### My Journey into Embedded Systems & Electronics

Welcome to my ESP32 project repository!

This repository documents my hands-on learning journey in electronics, microcontrollers, and embedded systems. Through a series of progressively challenging projects, I aim to strengthen my understanding of hardware-software integration, circuit design, and microcontroller programming.

Each project includes its source code, circuit connections, working principles, and key learnings.

**Software**
- Visual Studio Code
- PlatformIO
- Arduino Framework
- C/C++
- GitHub

## Learning Objectives

Through these projects, I aim to:

- Develop a strong foundation in practical electronics.
- Understand microcontroller architecture and GPIO operations.
- Learn to interface sensors and actuators.
- Improve embedded C/C++ programming skills.
- Gain experience debugging hardware and software.
- Explore wireless communication and IoT applications.
- Progress towards designing independent embedded systems projects.
