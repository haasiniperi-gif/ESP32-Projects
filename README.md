
# ESP32 Projects

This repository documents my journey learning electronics, microcontrollers, and embedded systems through hands-on projects.

## Project 01: LED Blinking

### Objective
To control an external LED using the GPIO pins of an ESP32 microcontroller.

### Components Used
- ESP32 DevKit V1
- Breadboard
- Red LED
- 220Ω resistor
- Jumper wires
- USB cable

### Software Used
- Visual Studio Code
- PlatformIO
- Arduino Framework (C++)

### Working Principle
The ESP32 controls an LED by switching a GPIO pin between HIGH and LOW.

The LED remains ON for one second and OFF for one second, repeating continuously.

### What I Learned
- Configuring GPIO pins as outputs
- Understanding HIGH and LOW signals
- Using `digitalWrite()` and `delay()`
- Understanding LED polarity and current-limiting resistors
- Troubleshooting GPIO and breadboard connections
- Uploading code to a microcontroller
